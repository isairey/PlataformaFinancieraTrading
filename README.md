# 📈 Acerca del proyecto

**Fincept Terminal** es una plataforma financiera open source enfocada en ofrecer herramientas profesionales para análisis financiero, trading algorítmico, inteligencia artificial y análisis cuantitativo desde una aplicación de escritorio completamente nativa.

El proyecto fue desarrollado para:

- 📊 Analizar mercados financieros
- 🤖 Automatizar procesos con IA
- 📈 Gestionar portafolios e inversiones
- 🌐 Conectar múltiples proveedores de datos
- ⚡ Ejecutar trading en tiempo real
- 🧠 Implementar modelos cuantitativos
- 🔬 Crear workflows financieros visuales

La plataforma combina el rendimiento de **C++20**, la potencia visual de **Qt6** y capacidades analíticas mediante **Python embebido**.

# 🚀 Configuración del proyecto

## 1️⃣ Clonar repositorio

```bash
git clone https://github.com/isairey/PlataformaFinancieraTrading.git
```

---

## 2️⃣ Entrar al proyecto

```bash
cd PlataformaFinancieraTrading
```

---

## 3️⃣ Instalación rápida

```bash
chmod +x setup.sh
./setup.sh
```

---

## 4️⃣ Compilar proyecto

```bash
cmake --preset linux-release
cmake --build --preset linux-release
```

---

## 5️⃣ Ejecutar plataforma

```bash
./build/linux-release/FinceptTerminal
```

---

# 💻 Ejemplo de compilación

## ⚙️ Build manual

```bash
cmake -B build/linux-release -G Ninja \
  -DCMAKE_BUILD_TYPE=Release
```

```bash
cmake --build build/linux-release
```

---

## 🐳 Docker

```bash
docker build -t fincept-terminal .
docker run fincept-terminal
```
